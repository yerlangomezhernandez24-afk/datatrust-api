# Prompt 04 — Métricas reproducibles sin inventar resultados

Prepara un generador de datos sintéticos y un script de benchmark local con lotes de 100, 1.000 y 10.000 filas. Define el hardware, Python, sistema operativo, tamaño de los archivos, regla de medición y warm-up. Ejecuta de verdad (si el entorno lo permite) y produce datos exportables; si no, deja scripts y di explícitamente que falta ejecutar.

Calcula throughput y latencia, compara contra una implementación sencilla y discute límites. No fabriques un ahorro de tiempo empresarial ni un porcentaje de precisión no medido.
