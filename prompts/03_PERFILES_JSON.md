# Prompt 03 — Validación por contratos JSON (fase posterior)

Diseña e implementa incrementalmente un formato seguro y documentado de perfiles de datos para que una persona defina reglas permitidas: columnas requeridas, tipos, rangos y valores de catálogo. No uses eval ni ejecutes código recibido. Incluye migración opcional del perfil orders_v1, casos de prueba para entradas no confiables y errores controlados. No rompas compatibilidad con la API anterior.

En cada paso describe qué aprendí de Pydantic, OpenAPI, validaciones y diseño de esquemas, sin afirmar que el proyecto ya es generalista antes de haberlo probado.
