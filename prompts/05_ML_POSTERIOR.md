# Prompt 05 — Machine Learning opcional (solo luego de consolidar MVP)

Necesito aprender ML aplicado a calidad de datos, no colocar un chatbot decorativo. Propón un experimento con dataset sintético etiquetado y modelo local scikit-learn para detectar anomalías numéricas. Establece baseline de reglas deterministas, split de entrenamiento/prueba sin filtración de datos, F1, precision, recall, falsos positivos y curvas de rendimiento. Implementa con tests y reproducibilidad.

No conectes servicios de pago, no uses información privada y no informes métricas hasta ejecutarlas. Explica en español en qué casos ML NO aporta sobre reglas normales.
