    Errores frecuentes

    422 · Estructura

    Revisa UTF-8, encabezados, columnas y máximo de filas.

    413 · Tamaño

    Reduce el CSV a 2 MiB y respeta el límite del request multipart.

    503 · SQLite ocupado

    Espera un momento y reintenta; la demo usa un solo writer.
